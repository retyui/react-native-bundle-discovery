New `--compare <before.json>` option for the `server` and `build` commands: adds a "Compare" tab to the default page with the difference between the two reports (bundle size, modules and packages count, new duplicates and deprecated packages, package version changes, added/removed/changed modules). Uses the same comparison as `react-native-bundle-discovery-cli compare`.
